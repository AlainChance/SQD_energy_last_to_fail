# Replication package — "The energy is the last thing to fail"

Scripts, result files, per-iteration one-body density matrices and run logs behind the tables and figures of the
manuscript, grouped by experiment. Each folder's scripts are the ones that produced the files beside them, and every
script reads and writes its files relative to its own directory, so a folder runs as it stands; `logs/` holds the run
logs and `figures/` is where the plotters write.

| folder | manuscript | contents |
|---|---|---|
| n2_equilibrium | §2, §3.1–3.5, Figures 1–3, Tables 3–6 | run of record from the archived ibm_fez samples, selected-CI references, controls A′/A″/B/C, Hamiltonian-variance extrapolation; `sqd_rdm1_*.npy` are the active-space 1-RDMs of every iteration, `sci_rdm1_*.npy` those of the references |
| n2_prior_diagnostic | §2.5, Table 2 | where the occupancy prior fails, N₂ and BeH₂ |
| n2_stretched | §3.6.1, Table 8 | (10e,16o) 6-31G on IBM's bond-length grid: hardware, matched-shot, random, occupation and configuration priors, in-sector strings, exact and noisy evolved-state seeds |
| n2_evolved_sampler | §3.6.3, Table 10 | (10e,12o) time-evolution scan, 16-orbital Krylov timing, double-factorized Trotter gate counts; the circuit-parameter optimizations to convergence (four runs: parameters, energies, sampled sets, set algebra against the evolved state) |
| n2_solver_envelope | §3.6.4, Table 12 | the addon's selected-CI solver on the recovered control subspaces and on random cuts of their pooled strings up to fifty million determinants: wall time, peak memory, energies |
| fe4s4_sbd | §3.6.2, Table 9, §3.7.6 | the recovery loop on the sbd eigensolver for [4Fe-4S] (54e,36o): hardware, occupation prior, configuration prior with and without the spin penalty, in-sector strings, equal-size pair; spin recomputation; multi-start and raw-subspace tests |
| sbd_fork | §2.4, §3.7.6, §5 | spin-penalty patch against upstream sbd commit 293b409, build and smoke scripts, validation against the exact projected operator, two-string unit test, install record |

## External inputs (not included)

- N₂ hardware samples and the pipeline of the run of record: the SQD_Alain repository (`N2/N2_cc-pvdz_ibm_fez_manual/N2_cc-pvdz_bitarray.npy`).
- Iron–sulfur samples, integrals (`integrals/4Fe-4S/fcidump_Fe4S4_MO.txt`) and reference energies: IBM's SQD data archive, Zenodo record 10.5281/zenodo.15324153.
- sbd: https://github.com/r-ccs-cms/sbd at commit 293b409, patched by `sbd_fork/patch_sbd_spin_penalty.py`; qiskit-addon-sqd 0.12.1; pyscf; ffsim; qiskit.

## Environment

Python 3 with numpy, scipy, pyscf, qiskit-addon-sqd, ffsim, qiskit and matplotlib; for `fe4s4_sbd` and `sbd_fork` a conda
environment (`sqdhpc`: cmake, OpenMPI, mpi4py, OpenBLAS, Eigen, Boost) as recorded in `sbd_fork/build/sqd_hpc_addon_install.md`.
The scripts keep the absolute paths of the machine they ran on (`/home/alain/...`) as constants near the top of each file; set
them to the local locations of the external inputs, the sbd binary and the conda environment before running.

Files not packaged because they are regenerated by the scripts: the sbd working directories (string lists and wavefunctions,
1.2 GB), the N₂ subspace vectors (`sqd_state_*.npz`, 0.8 GB; also the inputs of `n2_solver_envelope`), and the state vectors of the
optimized circuits (the `vec` array of the `lucj_overlap_*.npz` files, 10 MB each; `lucj_overlap_small.py` rebuilds them from the saved
parameters `x`).
